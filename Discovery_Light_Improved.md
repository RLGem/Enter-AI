# **📖 The Mom Test - הכלל הזהב**

**⏱️ 10 דקות**

## 🧠 מה זה The Mom Test?

```
┌────────────────────────────────────────────┐
│ 📚 ספר מאת Rob Fitzpatrick                │
│                                            │
│ 🎯 הרעיון המרכזי:                         │
│ "אל תשאל את אמא שלך אם הרעיון שלך טוב"   │
│                                            │
│ למה?                                       │
│ כי היא תאמר "כן מותק, זה נפלא!"           │
│ גם אם זה נורא.                             │
└────────────────────────────────────────────┘
```

## 📏 3 הכללים של The Mom Test

### כלל 1️⃣: דבר על החיים שלהם, לא על הרעיון שלך

```
┌────────────────────────────────────────────┐
│ ❌ רע:                                     │
│ "האם תשתמש באפליקציה לתכנון אירועים?"     │
│ (קל לומר כן)                              │
│                                            │
│ ✅ טוב:                                    │
│ "ספר לי איך תכננת את החתונה שלך"          │
│ (אמת!)                                     │
└────────────────────────────────────────────┘
```

### כלל 2️⃣: שאל על התנהגות עבר, לא על עתיד

```
┌────────────────────────────────────────────┐
│ ❌ רע:                                     │
│ "האם תשתמש ב-X אם נבנה אותו?"             │
│                                            │
│ ✅ טוב:                                    │
│ "מה עשית בפעם האחרונה שנתקלת ב-Y?"        │
│                                            │
│ ❌ רע:                                     │
│ "האם תשלם 50₪ לחודש?"                     │
│                                            │
│ ✅ טוב:                                    │
│ "כמה שילמת על כלים לתכנון?"               │
└────────────────────────────────────────────┘
```

### כלל 3️⃣: דבר פחות, שמע יותר

```
┌────────────────────────────────────────────┐
│ 👤 אתה: 20% מהשיחה                        │
│ 👥 הם: 80% מהשיחה                         │
│                                            │
│ אתה שואל → הם מספרים → אתה שואל follow-up │
└────────────────────────────────────────────┘
```

```

### שלב 2: הגדר קהל יעד ספציפי

```

│        האחרונים"                           │
│                                            │
│ ❌ רע: "אנשים שרוצים להתאמן"              │
│ ✅ טוב: "אנשים שהצטרפו לחדר כושר          │
│        אבל הפסיקו אחרי חודש"              │
└────────────────────────────────────────────┘
```

### שלב 3: מצא 5-10 אנשים

```
┌────────────────────────────────────────────┐
│ 🔍 איפה מוצאים?                           │
│                                            │
│ 1. חוג מכרים - חברים, משפחה               │
│ 2. קבוצות פייסבוק רלוונטיות               │
│ 3. LinkedIn                                │
│ 4. Reddit / פורומים                        │
│ 5. בקשה מחבר: "מכיר מישהו ש...?"          │
└────────────────────────────────────────────┘
```

## Interview Script (15-20 דקות)

```
┌────────────────────────────────────────────┐
│ 📝 מבנה השיחה:                            │
│                                            │
│ 1️⃣  Context (5 דקות)                      │

│    "מה היה הצעד הראשון?"                  │
│                                            │
│ 2️⃣  Problems (10 דקות)                    │

│                                            │
│ 3️⃣  Solutions (3 דקות)                    │

│    "מה עבד? מה לא?"                       │
│                                            │
│ 4️⃣  Wrap-up (2 דקות)                      │
│    "מה היית משנה?"                        │
│    "מכיר עוד מישהו?"                      │
└────────────────────────────────────────────┘
