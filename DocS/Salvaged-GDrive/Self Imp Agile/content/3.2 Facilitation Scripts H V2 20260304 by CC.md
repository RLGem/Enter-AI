# תסריטי הנחיה — מה לומר, דקה אחרי דקה

> **גרסה:** 2.0 | **תאריך:** 04.03.2026
> **קהל יעד:** Scrum Master — המנחה של כל הטקסים
> **זמן קריאה:** 10 דקות (או פתח/י את התסריט הרלוונטי לפני כל טקס)
> **תוצר:** את/ה יודע/ת בדיוק מה להגיד בכל רגע

---

## TL;DR — אם יש לך רק דקה

1. **כל טקס = תסריט.** לא צריך להמציא. פשוט עקוב/בי.
2. **הכנה = 50% מההצלחה.** הגע/י 15 דקות לפני עם הכל מוכן.
3. **תגיד/י את המשפטים כמו שהם.** עם הזמן תתאים/י לסגנון שלך.
4. **כשמישהו חורג — חניון.** המשפט הכי חשוב: "נושא מעולה — בואו נמשיך אחרי."
5. **שאל/י את AIlex לפני כל טקס:** "אני SM, מחר יש לי [טקס]. מה להכין?"

---

## תסריט 1: Daily Standup (15 דקות)

### הכנה (SM, 2 דקות לפני)

- [ ] בדוק/י לוח: פריטים תקועים יותר מיומיים?
- [ ] רשום/י חסימות מאתמול
- [ ] טיימר מוכן

### פתיחה (SM, 30 שניות)

</div>

```
"בוקר טוב. בואו נעשה Daily.
 תזכורת: מה עשית, מה תעשה היום, מה חוסם אותך.
 נשמור על קצר.
 [שם], רוצה להתחיל?"
```

<div dir="rtl">

### סיבוב (כל אחד, ~1.5 דקות)

</div>

```
← אם מישהו מאריך:
  "תודה [שם] — פירוט מעולה. בואו ניקח את הפרטים
   אחרי. הבא?"

← אם מישהו מציין חסימה:
  "קיבלתי. אני לוקח/ת את זה. [שם], בואו נסנכרן
   מיד אחרי ה-Daily."

← אם שניים מתחילים לדון:
  "חניון — נושא מעולה. ניקח את זה
   מיד אחרי רק עם מי שרלוונטי."
```

<div dir="rtl">

### סגירה (SM, 30 שניות)

</div>

```
"תודה לכולם. חסימות היום:
 [רשימה + אחראים].
 חניון: [שם] ו-[שם] — הישארו ל-5 דקות.
 כולם — יום פרודוקטיבי."
```

## תסריט 2: Sprint Planning (3-4 שעות)

### הכנה (SM, 30 דקות לפני)

- [ ] אישור: PO סידר Backlog + הציע Sprint Goal
- [ ] חישוב קיבולת צוות (ימי עבודה − היעדרויות)
- [ ] Velocity מ-3 ספרינטים אחרונים
- [ ] Azure DevOps: Sprint iteration חדש מוגדר

### חלק 1 — מה (60-90 דקות)

#### פתיחה (SM, 5 דקות)

</div>

```
"ברוכים הבאים ל-Sprint [N] Planning.
 [PO], בבקשה שתף/י את ה-Sprint Goal המוצע
 ותעבור/תעברי על פריטי ה-Backlog המובילים."
```

<div dir="rtl">

#### PO מציג (PO, 20-30 דקות)

‏PO מציג 8-12 Stories מובילים. SM עוקב אחרי שאלות מהצוות.

#### שאלות הצוות (כולם, 20-30 דקות)

</div>

```
SM: "שאלות? משהו לא ברור?"

← אם שאלה הולכת עמוק מדי:
  "שאלה טובה — בואו נרשום אותה
   ונחדד בזמן פירוק ל-Tasks."
```

<div dir="rtl">

#### בחירה (כולם, 15-20 דקות)

</div>

```
SM: "ה-Velocity הממוצע שלנו הוא [X] נקודות.
 הקיבולת בספרינט הזה: [Y] ימי-אדם.
 בהתבסס על מה ששמענו, על כמה Stories
 אנחנו יכולים להתחייב בצורה ריאלית?"

[הצוות בוחר Stories. PO מאשר Sprint Goal.]

SM: "ה-Sprint Goal שלנו הוא: [קורא בקול].
 כולם מיושרים? ... מעולה. בואו נפרק."
```

<div dir="rtl">

**--- הפסקה 10 דקות ---**

### חלק 2 — איך (90-120 דקות)

#### לכל Story:

</div>

```
SM: "[PO], הבהרה אחרונה על Story [X]?"
SM: "צוות, אילו Tasks נדרשים כדי להשלים את זה?"

[הצוות מזהה Tasks, מעריך בשעות.]

‏SM עוקב אחרי סך רץ מול הקיבולת.

← אם סך השעות > קיבולת:
  "אנחנו ב-[X] שעות מתוך [Y] קיבולת.
   מה צריך להתאים?"
```

<div dir="rtl">

#### סגירה (SM, 10 דקות)

</div>

```
"Sprint Goal: [קורא בקול]
 Stories שהתחייבנו: [רשימה]
 סה"כ מוערך: [X] שעות / [Y] קיבולת
 חששות? ... מעולה. Sprint [N] מתחיל עכשיו."
```

## תסריט 3: Backlog Refinement (שעה)

### הכנה (SM, 10 דקות לפני)

- [ ] אישור: PO הכין 5-8 Stories לדיון
- [ ] הפץ/י רשימת Stories לצוות לעיון
- [ ] קלפי Planning Poker / אפליקציה מוכנים

### פתיחה (SM, 3 דקות)

</div>

```
"היום אנחנו מחדדים Stories לספרינט [N+1].
 [PO] יציג כל Story. נבהיר, נעריך, ונפרק אם צריך.
 המטרה: כל ה-Stories עומדים ב-Definition of Ready."
```

<div dir="rtl">

### לכל Story (8-10 דקות):

#### 1. PO מציג (2 דקות):
‏PO קורא Story + Acceptance Criteria.

#### 2. שאלות צוות (3 דקות):

</div>

```
SM: "שאלות?"

← שים לב ל: AC מעורפלים, מקרי קצה חסרים,
   תלויות לא ידועות
```

<div dir="rtl">

#### 3. הערכה (3 דקות):

</div>

```
SM: "קלפים מוכנים? ... חושפים."

← אם הסכמה: רשום והמשך.
← אם פיזור: "גבוה ונמוך, הסבירו את השיקולים."
   אז הצבעה חוזרת.
```

<div dir="rtl">

#### 4. בדיקת פירוק (דקה):

</div>

```
SM: "זה [X] נקודות. מעל 8?"
← אם כן: "בואו נפרק. מה הם התפרים הטבעיים?"
```

<div dir="rtl">

### סגירה (SM, 5 דקות)

</div>

```
"חידדנו [N] Stories. [X] עומדים ב-DoR.
 [Y] צריכים עוד עבודה — PO, אפשר לעדכן
 את ה-AC עד [יום]? נתראה ב-Planning."
```

## תסריט 4: Sprint Review (עד שעתיים)

### הכנה (SM, 15 דקות לפני)

- [ ] סביבת Demo עובדת
- [ ] PO הכין סיכום ביצוע
- [ ] בעלי עניין אישרו הגעה
- [ ] סדר הדגמות מוסכם עם הצוות

### פתיחה (PO, 10 דקות)

</div>

```
"ברוכים הבאים ל-Sprint [N] Review.
 ה-Sprint Goal שלנו היה: [קורא את ה-Goal].
 השלמנו [X] מתוך [Y] Stories.
 [סיכום קצר של מה שנבנה.]
 עכשיו הצוות ידגים את התוכנה."
```

<div dir="rtl">

### הדגמה (צוות הפיתוח, 60 דקות)

כל מפתח/ת מדגים/ה את ה-Stories שהשלים/ה.

</div>

```
← SM לבעלי עניין:
  "אל תהססו לשאול שאלות תוך כדי."

← אם שאלה הולכת עמוק מדי לטכני:
  "שאלה מעולה — בואו נתעד אותה
   והצוות יעקוב."

← בין הדגמות:
  "[שם], את/ה הבא/ה עם [Story]."
```

<div dir="rtl">

### משוב (SM מנחה, 20 דקות)

</div>

```
SM: "תודה על ההדגמות. עכשיו נשמח למשוב."

שאלות מנחות:
  - "זה מתאים למה שציפיתם?"
  - "מה הייתם משנים?"
  - "מה הכי בעל ערך עבורכם?"
  - "חסר משהו?"

‏SM מתעד כל פריט משוב.
```

<div dir="rtl">

### תצוגה מקדימה (PO, 15 דקות)

</div>

```
PO: "בהתבסס על המשוב היום וה-Roadmap שלנו,
 הנה מה שאנחנו מסתכלים עליו לספרינט הבא: [...]
 משהו לגבי סדרי עדיפויות?"
```

<div dir="rtl">

### סגירה (SM, 5 דקות)

</div>

```
"תודה לכולם. משוב מרכזי שנתפס:
 [רשימת 3-5 פריטים].
 נשלב את זה בתכנון. נתראה בעוד 3 שבועות."
```

## תסריט 5: Sprint Retrospective (עד שעה וחצי)

### הכנה (SM, 15 דקות לפני)

- [ ] בחר/י פורמט (החליפו! אל תחזרו על הפעם הקודמת)
- [ ] הכן/י לוח/כלי (Miro, פתקים, וכו')
- [ ] הכן/י Action Items מ-Retro הקודם
- [ ] ודא/י: החדר בטוח (בלי מנהלים!)

### שלב 1: פתיחה (5 דקות)

</div>

```
"ברוכים הבאים ל-Retro של Sprint [N].
 תזכורת — Prime Directive:
 'כולם עשו את המיטב שיכלו עם מה שידעו
 באותו הזמן.'
 זה מרחב בטוח. בואו נהיה כנים."
```

<div dir="rtl">

### שלב 2: סקירת Action Items קודמים (5 דקות)

</div>

```
"לפני שמתחילים, בואו נבדוק Action Items
 מ-Retro הקודם:
 1. [פריט] — [בוצע/לא/בתהליך]
 2. [פריט] — [בוצע/לא/בתהליך]
 הערות?"

← אם לא בוצע:
  "מה חסם את זה? נמשיך להתמיד
   או נוותר?"
```

<div dir="rtl">

### שלב 3: איסוף נתונים (15-20 דקות)

דוגמה: פורמט Start / Stop / Continue

</div>

```
"קחו 5 דקות של כתיבה שקטה.
 חשבו על הספרינט הזה:
 - מה כדאי להתחיל לעשות?
 - מה כדאי להפסיק לעשות?
 - מה כדאי להמשיך לעשות?

 פריט אחד לפתק. כמה שרוצים."

[SM מפעיל טיימר ל-5 דקות כתיבה שקטה.]

"זמן. בואו נדביק ואני אקבץ
 פריטים דומים."
```

<div dir="rtl">

### שלב 4: קיבוץ ודיון (20-30 דקות)

‏SM מקבץ פריטים דומים.

</div>

```
"אני רואה [N] נושאים. בואו נדון
 בקבוצות הגדולות."

לכל נושא:
SM: "מי רוצה לספר עוד על זה?"

← אם מישהו שולט:
  "תודה [שם]. למישהו יש
   נקודת מבט נוספת?"

← אם שקט:
  "אני אבחר אחד: [קורא פריט]. מי כתב?
   אפשר לספר עוד?"
```

<div dir="rtl">

### שלב 5: הצבעה (5 דקות)

</div>

```
"כל אחד מקבל 3 נקודות. שימו אותן
 על הפריטים שהכי חשוב לטפל בהם."
```

<div dir="rtl">

### שלב 6: Action Items (15-20 דקות)

</div>

```
"הפריטים שקיבלו הכי הרבה הצבעות: [1], [2], [3].
 לכל אחד, בואו נגדיר:
 - מה בדיוק נעשה?
 - מי אחראי?
 - עד מתי?"

← אם Action מעורפל:
  "אפשר להיות יותר ספציפיים?
   מה בדיוק ישתנה?"

"מקסימום 2-3 Action Items. אני מוסיף/ה
 אותם כ-Tasks ב-Backlog של הספרינט הבא."
```

<div dir="rtl">

### שלב 7: סגירה (5 דקות)

</div>

```
"ה-Action Items שלנו:
 1. [פעולה] — אחראי: [שם] — עד: [תאריך]
 2. [פעולה] — אחראי: [שם] — עד: [תאריך]

 תודה על השיחה הכנה.
 [הערכה ספציפית למשהו שקרה בספרינט.]"
```
