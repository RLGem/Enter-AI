# מדריך הגדרת Azure DevOps — צעד אחר צעד

> **גרסה:** 2.0 | **תאריך:** 04.03.2026
> **קהל יעד:** Scrum Master + מנהל/ת (הגדרה ראשונית)
> **זמן קריאה:** 8 דקות
> **תוצר:** Azure DevOps מוכן לספרינט הראשון

---

## TL;DR — אם יש לך רק דקה

1. **הגדר Sprint iteration** — שם, תאריכים (3 שבועות), קיבולת.
2. **סדר את הלוח** — 5 עמודות: New → Active → In Review → Testing → Done.
3. **צור Work Items** — User Stories עם Tasks מתחתם.
4. **בנה Dashboard** — Burndown + Velocity + Sprint Overview.
5. **שאל/י את AIlex** אם נתקעת: "אני SM, איך מגדירים [X] ב-Azure DevOps?"

---

## 1. הגדרת ספרינט חדש (Sprint Setup)

### 1.1 יצירת Iteration

</div>

```
נתיב: Project Settings → Team Configuration → Iterations
  → + New child
  → שם: "Sprint [N]"
  → תאריך התחלה: [ראשון של שבוע 1]
  → תאריך סיום: [חמישי של שבוע 3]  ← 3 שבועות!
  → Save
```

<div dir="rtl">

### 1.2 שיוך פריטים לספרינט

</div>

```
אפשרות 1 — גרירה:
  Boards → Backlogs → גרור פריטים לתוך Sprint [N]

אפשרות 2 — עריכה:
  פתח פריט → שדה Iteration → בחר Sprint [N]
```

<div dir="rtl">

### 1.3 הגדרת קיבולת (Capacity)

</div>

```
Boards → Sprints → [Sprint N] → לשונית Capacity
  → הכנס שעות/יום לכל חבר צוות
  → סמן Days Off (חופשות, חגים)

טיפ: קיבולת = (ימי עבודה) × (שעות/יום) × (מפתחים)
     − חופשות − רזרבות − 20% תקורה (טקסים + מנהלתי)
```

## 2. הגדרת הלוח (Board Configuration)

### 2.1 עמודות

</div>

```
נתיב: Boards → Board → Settings (אייקון גלגל שיניים) → Columns
  → הוסף/שנה שם/סדר עמודות

מבנה מומלץ:
┌──────────┬──────────────┬───────────────┬──────────────┬──────────┐
│   New    │   Active     │  In Review    │   Testing    │   Done   │
│  (חדש)   │  (בעבודה)    │ (בסקירת קוד) │  (בבדיקות)   │  (הושלם) │
└──────────┴──────────────┴───────────────┴──────────────┴──────────┘
```

<div dir="rtl">

### 2.2 הגבלת WIP (Work In Progress)

</div>

```
Board Settings → Columns → לחץ על עמודה
  → הגדר "Max items" (הגבלת WIP)

המלצה:
  Active: מקסימום 2 × מספר מפתחים
  In Review: מקסימום מספר מפתחים
  Testing: מקסימום מספר מפתחים
```

<div dir="rtl">

### 2.3 Swimlanes (נתיבי שחייה)

</div>

```
Board Settings → Swimlanes
  → + Swimlane → שם: "Expedite" (דחוף)
  → + Swimlane → שם: "Bugs" (באגים)
  → + Swimlane → שם: "Tech Debt" (חוב טכני)
```

<div dir="rtl">

### 2.4 שדות בכרטיסים

</div>

```
Board Settings → Fields
  → סמן: Title, Assigned To, Story Points, Tags, Remaining Work
```

<div dir="rtl">

### 2.5 כללי צבע (Style Rules)

</div>

```
Board Settings → Styles
  → + Styling rule → שם: "Blocked"
  → כלל: Tag = "Blocked" → צבע: אדום

  → + Styling rule → שם: "Bug"
  → כלל: Work Item Type = Bug → צבע: כתום
```

## 3. יצירת Work Items

### 3.1 User Story

</div>

```
Boards → Backlogs → + New Work Item → סוג: User Story
  → Title: "בתור [תפקיד], אני רוצה [פעולה]..."
  → Description: הסיפור המלא + הקשר
  → לשונית Acceptance Criteria: הוסף קריטריונים
  → Story Points: [הערכה]
  → Area Path: [אזור הצוות]
  → Iteration Path: [Sprint — אם שויך]
```

<div dir="rtl">

### 3.2 Task (תחת Story)

</div>

```
פתח Story → Related Work → + Add link
  → Link type: Child → New Item → סוג: Task
  → Title: [תיאור המשימה]
  → Assigned To: [מפתח/ת]
  → Remaining Work: [שעות]
```

<div dir="rtl">

### 3.3 Bug

</div>

```
Boards → + New Work Item → סוג: Bug
  → Repro Steps: [שלבים לשחזור]
  → System Info: [מידע מערכת]
  → Severity: [1-Critical / 2-High / 3-Medium / 4-Low]
  → קשר ל-Story רלוונטי אם יש
```

## 4. בניית Dashboard

### 4.1 יצירת Dashboard

</div>

```
Overview → Dashboards → + New Dashboard
  → שם: "[שם הצוות] Sprint Dashboard"
```

<div dir="rtl">

### 4.2 Widget: Sprint Burndown

</div>

```
+ Add Widget → חפש "Sprint Burndown"
  → הגדר: צוות, Sprint iteration
```

<div dir="rtl">

### 4.3 Widget: Velocity

</div>

```
+ Add Widget → חפש "Velocity"
  → הגדר: מספר ספרינטים להצגה (3-5)
```

<div dir="rtl">

### 4.4 Widget: Cumulative Flow

</div>

```
+ Add Widget → חפש "Cumulative Flow Diagram"
  → הגדר: צוות, טווח זמן, עמודות לוח
```

<div dir="rtl">

### 4.5 Widget: Sprint Overview

</div>

```
+ Add Widget → חפש "Sprint Overview"
  → מציג: סה"כ Stories, הושלמו, בעבודה, לא התחילו
```

## 5. שאילתות שימושיות (Queries)

### Stories לא סיימנו בספרינט

</div>

```
Boards → Queries → + New Query
  → Work Item Type = User Story
  → Iteration Path = @CurrentIteration
  → State <> Done
  → Run query
```

<div dir="rtl">

### פריטים שעברו מספרינט קודם (Carryover)

</div>

```
  → Work Item Type = User Story
  → Iteration Path = @CurrentIteration
  → Created Date < [תאריך תחילת ספרינט]
```

<div dir="rtl">

### פריטים חסומים

</div>

```
  → Tags Contains "Blocked"
  → State <> Done
```
