# שאלו את AIlex — מדריך לשיחה עם המאמן ה-Agile שלך

> **גרסה:** 2.0 | **תאריך:** 02.03.2026
> **קהל יעד:** כל חברי הצוות — מפתחים, Product Owners, Scrum Masters, מנהלים, לקוחות
> **זמן קריאה:** 5 דקות

---

## מה זה AIlex?

**AIlex** הוא מאמן Agile מבוסס AI שמחליף יועץ חיצוני. הוא:
- **נותן כלים ביד** — צ'קליסטים, תסריטים, פלייבוקים — לא רק הסברים
- **מתאים את עצמו אליך** — לתפקיד שלך, לרמת הניסיון שלך, ולשבוע בספרינט
- **עובד בשיטת "נעשה ונשמע"** — קודם עושים, אחר כך מבינים

### שלב 3: התחל לדבר!

AIlex ישאל אותך 3 שאלות קצרות:
1. **מה התפקיד שלך?** (Developer / PO / SM / Manager / Client)
2. **באיזה שבוע של הספרינט אתם?** (1 / 2 / 3 / בין ספרינטים)
3. **מה האתגר או השאלה?** (טקס / תקיעות / בעיה צוותית / למידה / אחר)

ומיד — תקבל כלי מוכן.

### שלב 4 (אופציונלי): שמור את כרטיס ההקשר
בסוף ההיכרות הראשונה, AIlex ייצור לך **כרטיס הקשר**. שמור אותו — בפעם הבאה, תדביק אותו בתחילת השיחה וידלגו על השאלות.

### מפתח/ת (Developer)

</div>

```
1. "אני מפתח/ת, שבוע 1. יש לנו Planning מחר — מה אני צריך/ה להכין?"

2. "אני מפתח/ת, שבוע 2. יש לי Task שנתקע כבר יומיים — מה עושים?"

3. "אני מפתח/ת. ה-Daily שלנו ארוך מדי ולא אפקטיבי. יש רעיון?"

4. "אני מפתח/ת. אני לא מבין/ה למה צריך Story Points — אפשר פשוט לעבוד?"

5. "אני מפתח/ת, שבוע 3. יש לנו Review בעוד יומיים ואני לא בטוח/ה שנסיים. מה לעשות?"

6. "אני מפתח/ת חדש/ה ב-Agile. מה אני צריך/ה לדעת כדי להצליח?"

7. "אני מפתח/ת. ה-PO שלנו משנה דרישות באמצע הספרינט. איך מתמודדים?"

8. "אני מפתח/ת. מה זה Definition of Done ואיך זה עוזר לי?"
```

## טיפים לשיחה טובה עם AIlex

### כן — עשו ככה:

| טיפ | דוגמה |
|----:|:------|
| **ציינו תפקיד** | "אני SM, שבוע 2..." |
| **היו ספציפיים** | "ה-Daily שלנו ארוך — 25 דקות במקום 15" |
| **תארו מה קורה** | "חבר צוות אחד מדבר 10 דקות" |
| **הדביקו כרטיס הקשר** | הכרטיס שקיבלתם בפעם הראשונה |
| **בקשו כלי ביד** | "תן לי צ'קליסט / תסריט / פלייבוק" |
| **נושא אחד לשיחה** | עדיף שיחה ממוקדת על 3 נושאים מעורבבים |

### לא — אל תעשו ככה:

| טיפ | למה |
|----:|:----|
| **"תסביר לי Agile"** | רחב מדי — תשאלו על נושא ספציפי |
| **5 שאלות ברצף** | שאלה אחת → תשובה → שאלה הבאה |
| **"זה לא עובד"** | מה בדיוק לא עובד? תארו את המצב |

## בסוף כל שיחה

AIlex ייצור **סיכום אימון** שכולל:
- שרירים שאומנו
- תוצרים שקיבלת
- צעד אחד הבא
- חובות פתוחים (אם יש)

**העתיקו את הסיכום ושלחו למנהל המערכת (Admin)** — זה עוזר לשפר את AIlex ואת מאגר הידע.

## שאלות נפוצות

**ש: AIlex עונה באנגלית. מה עושים?**
ת: תוודאו שהעתקתם את קובץ הפרומפט (Agile Coach H V2) — הוא מכיל הוראות לענות בעברית. אם עדיין עונה באנגלית, כתבו: "ענה בעברית."

**ש: AIlex לא מכיר את הארגון שלנו.**
ת: הדביקו את כרטיס ההקשר בתחילת השיחה. זה נותן לו את הרקע.

**ש: AIlex נותן תשובה שלא מתאימה ל-3 שבועות ספרינט.**
ת: תזכירו לו: "אצלנו ספרינט של 3 שבועות" — הוא יתאים.

**ש: אפשר להשתמש ב-AIlex לנושאים שהם לא Agile?**
ת: AIlex מתמחה ב-Agile בלבד. לשאלות טכניות, פנו ל-Tech Lead. לשאלות ניהוליות, לממונה.

**ש: למי שולחים את סיכום האימון?**
ת: למנהל המערכת (Admin) שמוגדר בארגון. הסיכומים משמשים לשיפור מאגר הידע.
