## Task 1: הוסף משימה

```
┌────────────────────────────────────────────┐

│    עם הרשימה... אממ... מחפשת איפה        │
│    להוסיף... אולי ה-+ הזה למעלה?         │

│    אה כן! נפתח חלון. אני כותבת           │

│                                            │
```
